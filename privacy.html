Cel i dostęp do danych

Backup Praca to osobista konfiguracja rclone właściciela konta GitHub kryptoemeryt85-netizen. Korzysta z Google Drive API do porównywania, odczytu, tworzenia, aktualizowania i — przy synchronizacji — usuwania plików w folderze kopii wskazanym przez właściciela. Uprawnienie OAuth Google Drive umożliwia szerszy dostęp do Dysku Google niż pojedynczy folder; folder docelowy ogranicza konfiguracja programu.

Przechowywanie i przesyłanie

Dokumenty pozostają na dysku lokalnym i w kopii na koncie Google właściciela. Rclone przesyła dane między komputerem a Google przez połączenie HTTPS. Dane klienta OAuth i tokeny są przechowywane lokalnie w konfiguracji rclone. Lokalne dzienniki mogą zawierać nazwy plików i informacje o operacjach.

Udostępnianie

Konfiguracja nie wysyła dokumentów, haseł ani tokenów do tej strony lub repozytorium GitHub. Nie służy reklamie, sprzedaży danych ani trenowaniu modeli AI. Przetwarzanie przez Google podlega również zasadom konta Google i jego polityce prywatności.

Kontrola właściciela

Właściciel może wyłączyć zadanie synchronizacji, usunąć lokalną konfigurację i tokeny oraz cofnąć dostęp aplikacji w ustawieniach połączeń konta Google. Cofnięcie dostępu nie usuwa istniejących kopii; można je usunąć bezpośrednio z Dysku Google. Zasady retencji i kosza Google zależą od ustawień usługi.

Ta strona i kontakt

Strona nie zawiera analityki, formularzy ani własnych plików cookie. Jest hostowana przez GitHub Pages; GitHub może przetwarzać techniczne dane odwiedzin według swojej polityki prywatności. Kontakt z właścicielem: profil GitHub kryptoemeryt85.
